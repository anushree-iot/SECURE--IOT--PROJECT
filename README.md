# Secure IoT Project 🔒

IoT ke sensor data ko Blockchain se safe rakhne wala project.

## Ye Project Kya Karta Hai?
IoT devices se aane wala Temperature aur Humidity ka data aise hi save karne pe koi bhi badal sakta hai. Is project me har data ko ek Block me daala jata hai aur har Block ka ek unique Hash banta hai.

Agar koi beech me data badalta hai, to Hash badal jata hai aur pata chal jata hai ki data Hack ho gaya hai.

## Kaise Chalaye?
1. Python install karo
2. Terminal me ye likho:
python blockchain.py

## Technologies
- Python
- Blockchain (Hashing - SHA256)
- IoT Sensors (Temperature, Humidity)
